# 🩺 Diabuddy

A mobile application for managing life with diabetes, built with Flutter. Diabuddy helps users track their health data, monitor trends, and stay on top of their diabetes management, all from their phone.

---

## 🛠️ Technologies

| Technology | Purpose |
|---|---|
| **Flutter** (Dart) | Cross-platform mobile framework (iOS & Android) |
| **Firebase Auth** | User authentication |
| **Cloud Firestore** | Cloud database for storing health data |
| **Flutter BLoC** | State management |
| **fl_chart** | Data visualization / charts |
| **flutter_local_notifications** | Local push notifications |
| **shared_preferences** | Local storage for user preferences |
| **flutter_localizations / intl** | Internationalization support |

---

## ✨ Features

- 📊 **Health data tracking** — Log and monitor diabetes-related metrics over time
- 📈 **Charts & trends** — Visualize your data with interactive charts powered by fl_chart
- 🔔 **Local notifications** — Reminders to help you stay consistent with tracking
- 🔐 **Authentication** — Secure sign-in via Firebase Auth
- 🌍 **Localization** — Multi-language support
- 📱 **Cross-platform** — Runs on both iOS and Android

---

## 🚀 Running the Project

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) `>=2.18.1 <3.0.0`
- Dart SDK (included with Flutter)
- A Firebase project configured for Android and/or iOS
- Android Studio / Xcode (for running on emulator or device)
